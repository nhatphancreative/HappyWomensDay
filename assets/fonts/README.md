# Garden typography

PVN5 Garden Pixel is a bold derivative of Pixelify Sans by Stefie Justprince.
The original Latin glyph outlines are preserved; Vietnamese horn, hook-above,
dot-below and missing precomposed vowel glyphs were added in the same pixel style.
It is renamed and distributed under the SIL Open Font License in PixelifySans-OFL.txt.
Upstream: https://github.com/eifetx/Pixelify-Sans

VT323 by Peter Hull is the game UI font, with native Vietnamese coverage.
Upstream: https://github.com/phoikoi/VT323

Be Vietnam Pro is used for longer greeting text and form input.
Upstream: https://github.com/bettergui/BeVietnamPro

All fonts are hosted locally so text does not depend on Google Fonts loading.
