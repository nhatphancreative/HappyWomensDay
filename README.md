# 20/10 · Happy Vietnamese Women's Day

A small pixel garden game: arrange six flower pieces by hand, grow a rose, and reveal one of five randomized Vietnamese Women's Day wishes.

## Publish with GitHub Pages

This repository is a static site and needs no build step. The workflow in `.github/workflows/pages.yml` deploys the repository root to GitHub Pages whenever you push to `main` (or run it manually from Actions).

In the repository settings, set **Pages → Build and deployment → Source** to **GitHub Actions**. The deployment workflow publishes the site automatically.

## Local preview

Open `index.html` in a browser, or serve this folder with any static web server.
